# 📊 Automated Data Quality & Profiling Dashboard

An interactive web application built with **Python** and **Streamlit** for automated data profiling, quality inspection, and visual analytics. This project showcases data science and software engineering practices by transforming raw datasets into structured, actionable insights.

## 🚀 Features
- **Automated Data Ingestion:** Connects directly to a live housing prices dataset from GitHub.
- **Key Performance Indicators (KPIs):** Instant display of total rows and column dimensions.
- **Raw Data Profiling:** Interactive preview matrix for direct inspection.
- **Descriptive Statistical Matrix:** Automated calculation of statistical summary (Mean, Std, Min, Max, Quartiles) for all numerical features.
- **Visual Analytics Hub:** Integrated Seaborn distribution histogram with Kernel Density Estimation (KDE) to understand statistical distribution.

## 🛠️ Tech Stack
- **Core Language:** Python 3.14
- **Web Framework:** Streamlit
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
